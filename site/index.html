Open Data Ensemble

Your own Synkronus server in about 10 minutes

Synkronus is the server your phones sync with. It keeps your forms, your app and all collected data in one safe place that you control. You don't need to be a developer: you copy, you paste, and it sets itself up.

  • Secure HTTPS address, even without your own domain
  • Admin login made for you and saved on the server
  • Nightly backups and one-command updates

Built your app in the ODE App Builder? This is where it goes next.

What you need

A small rented serverUbuntu 24.04, 1 GB memory. About $6 a month at DigitalOcean, Hetzner, Vultr or any provider.
10 minutesMost of it is waiting while the server downloads the software.
Optional: a domainLike data.yourorg.org. Without one you get a free address that works right away.

Looking after your server

      
Open the server console and type any of these:

      

        

          
Type thisWhat it does

          
            
synkronus statusIs it running? Shows the address, version, last backup and free space

            
synkronus credentialsShows the address and admin login again

            
synkronus backupBacks up all data now (it also happens every night at 02:00, kept 7 days)

            
synkronus restore FILEPuts back a backup from /opt/synkronus/backups

            
synkronus updateBacks up, updates to the newest version, and goes back if anything fails

            
synkronus reset-admin-passwordSets a new admin password and shows it

            
synkronus logsShows recent messages, useful when asking for help

          
        

      

      
Backups are kept on the same server. Once a month, download one with your provider's file tools or scp, so you still have your data if the server is ever deleted.

    


    

      
If something goes wrong

      
“Port 80 is already used by another program”
Another web server is running. On a fresh server this shouldn't happen. If you want to replace it, run systemctl disable --now nginx apache2 and paste the install line again.

      
“HTTPS is not ready yet” or a certificate warning in the browser
Your provider's firewall may be blocking the server. Allow incoming ports 80 and 443 (DigitalOcean: Networking → Firewalls). If you use a domain, check that its A record points to the server's IP. HTTPS starts working by itself a few minutes after that.

      
“This server has less than 1 GB of memory”
Resize the server to at least 1 GB at your provider, then paste the install line again.

      
I lost the admin password
Type synkronus credentials in the server console. If you changed it in the Portal and forgot it, type synkronus reset-admin-password.

      
Can I run the install line again?
Yes. On a server that's already set up it changes nothing and shows the status. If an earlier attempt stopped halfway, it continues where it left off.

      
My server is at home or in an office, behind a router
Use route C. Phones can't reach a server behind a router directly, and a Cloudflare Tunnel solves that without opening any ports. To try it first without a domain, use the "Just want to try it?" line in route C.

      
Docker or Podman?
The installer uses Podman, a fully open-source container engine, and installs it for you. If Docker is already on the server, it uses Docker instead. You never need to use either directly.

    


    

      
What the install line runs

      
The installer is open source and lives in the official synkronus-quickstart repository. You can read it here before running it. It installs everything into /opt/synkronus and adds the synkronus command. Your passwords are created on your server and never leave it.
